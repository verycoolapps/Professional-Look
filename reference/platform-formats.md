## LINKEDIN

### Character and Word Limits
| Content Type | Limit |
|---|---|
| Post (feed) | 3,000 characters (~500 words) |
| Post visible before "see more" | ~210 characters (approximately 2–3 lines) |
| Article title | 100 characters |
| Article body | No limit (practical limit: 1,000–2,000 words) |
| Headline (profile) | 220 characters |
| About section (profile) | 2,600 characters |
| Comment | 1,250 characters |
| Connection request message | 300 characters |
| Job title | 100 characters |
| Featured section description | 2,000 characters |

### Optimal Performance Lengths
| Content Type | Optimal |
|---|---|
| Short post | 150–300 words |
| Medium post | 300–600 words |
| Long post | 600–900 words (diminishing returns beyond this) |
| Article | 1,000–2,000 words |
| Comment | 50–150 words |

### Formatting Conventions
- Blank line between paragraphs (mandatory for readability)
- Markdown does not render (no #headers, no **bold**, no _italic_)
- Bullet points work: use the Unicode bullet (•) or a dash (—)
- Numbers and emojis render correctly
- Hashtags: place at the end; 3–5 maximum
- Tagging: use @name; only tag people directly relevant to the post

### Post Anatomy
```
[Hook — 1–2 lines, visible before See More]
[blank line]
[Body paragraph 1]
[blank line]
[Body paragraph 2]
[blank line]
[Body paragraph 3]
[blank line]
[Close/CTA — 1–2 lines]
[blank line]
#hashtag1 #hashtag2 #hashtag3
```

## X / TWITTER

### Character Limits
| Content Type | Limit |
|---|---|
| Tweet | 280 characters |
| Links | 23 characters (all links count as 23) |
| Username | 15 characters |
| Bio | 160 characters |
| Thread (individual tweets) | 280 characters each |

### Formatting Conventions
- No formatting in tweets (no markdown, no bold)
- Hashtags and @ mentions work natively
- Lists: use line breaks or number manually
- Threads: reply to your own tweet; use (1/n) numbering for clarity
- Images: 1200 × 628 px recommended for link previews

### Thread Anatomy
```
Tweet 1: [Hook — the claim or promise that earns the read] (1/n)
Tweet 2: [Context or the foundation] (2/n)
Tweet 3–(n-1): [One specific point per tweet] 
Tweet n: [Landing — the synthesis] (n/n)
```

## TIKTOK

### Limits
| Content Type | Limit |
|---|---|
| Caption | 2,200 characters |
| Bio | 80 characters |
| Username | 24 characters |
| Comments | 150 characters |

### Video Specifications
| Spec | Requirement |
|---|---|
| Orientation | Vertical (9:16) |
| Resolution | 1080 × 1920 px |
| Aspect ratio | 9:16 |
| Max file size | 287.6 MB (iOS), 72 MB (Android) |
| Duration | 15 seconds to 10 minutes |
| Optimal duration | 30–90 seconds for professional content |

### On-Screen Text Zones
- **Top zone:** Creator name and audio (avoid overlapping)
- **Safe zone:** Center 80% of the frame (text placement)
- **Bottom zone:** Caption, hashtags, buttons (avoid overlapping)
- Text on screen: maximum 6–8 words per card; minimum 18pt equivalent font size at 1080p

## MEDIUM

### Publishing Specs
| Element | Standard |
|---|---|
| Optimal article length | 1,000–2,000 words |
| Title | No official limit; under 60 characters for SEO |
| Subtitle | Under 100 characters |
| Reading time display | Auto-calculated (approx. 200 words/minute) |

### Formatting conventions
- Markdown supported
- Headers (H2, H3) for scanability
- Pull quotes for emphasis
- Code blocks for technical content
- Maximum one image per 400 words (guideline)

## UNIVERSAL SAFE ZONES

Regardless of platform, follow these universal content dimension rules:

| Dimension | Universal Standard |
|---|---|
| Hook location | First 1–2 lines |
| Single idea per paragraph | Never combine two themes in one paragraph |
| Maximum paragraph length | 4 sentences for social; 5 sentences for professional long-form |
| CTA placement | End of content; one CTA per piece |
| Hashtag placement | End of post; never mid-sentence |
